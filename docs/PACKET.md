## 4. Insight

<!-- PEGAR AQUÍ -->

[Placeholder] El fallo no está en “detectar más”. Está en la entrega: quién agenda, para cuándo, a qué costo, y quién confirma que el paso ocurrió.

## 5. Solution / Working slice

<!-- PEGAR AQUÍ -->

Después de un tamizaje simulado de riesgo elevado de diabetes, SigueMX crea una ruta de cuidado con dueña nombrada (Ana Martínez), una sola acción, una fecha límite, una señal de asequibilidad, check-in estructurado, escalamiento y verificación humana simulada.

---

## 6. Why this is not a chatbot / diagnostic tool

<!-- PEGAR AQUÍ -->

No hay chequeo de síntomas. No hay diagnóstico. El producto empieza *después* de un resultado ya producido (simulado). La IA solo explica datos estructurados del caso.

---

## 7. Demo script (90 seconds)

<!-- PEGAR AQUÍ -->

1. Landing: “Detección es solo el inicio.”
2. Comenzar caso de ejemplo → resultado SIMULADO.
3. Ruta de cuidado: Ana, siguiente paso, 16 de septiembre, opción de menor costo, ACTION NEEDED.
4. Check-in incompleto se bloquea.
5. Reportar asistencia → VERIFICACIÓN PENDIENTE (el caso no se cierra).
6. Simular fecha vencida en un caso abierto → ESCALAMIENTO ACTIVADO.
7. Simular verificación de coordinadora → PASO VERIFICADO.

---

## 8. Risks / ethics

<!-- PEGAR AQUÍ -->

- No recoger datos reales de pacientes en este prototipo.
- Etiquetar todo como simulado.
- No consejo médico.
- El auto-reporte de la paciente no cierra el caso.
